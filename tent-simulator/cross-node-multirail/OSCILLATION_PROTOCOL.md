# O实验：均匀输入与固定均分下的权重往返复现

本轮目标仅是建立可重复、可审计的权重/分配往返基线，不筛选优化算法，不要求
先证明吞吐受损，也不把“变化次数很多”直接等同于周期震荡。旧A/B/C/E数据保留。

## 条件与对照

真实跨机：A10双eRDMA发送、erdma_test单eRDMA接收；Host内存，发送NUMA0，
双方6 lanes，1MiB/request，每API batch一request，Q128、单caller。
原alpha=0.01、jitter、探测周期保持不变。两档恒定计划输入为E恢复参考吞吐
9.6544Gbps的20%与60%；这是参考输入比例，不是硬件利用率。

| 组 | 原算法评分 | 实际Slice分配 |
| --- | --- | --- |
| native-free | 原环境的带宽输入/NUMA惩罚 | 原算法自由分配 |
| native-equal | 同上，计算的权重为旁路诊断 | 每request两NIC各一半字节 |
| symmetric-free | 两NIC相同10Gbps理论先验/边界、NUMA惩罚均1 | 原算法自由分配 |
| symmetric-equal | 同上，计算的权重为旁路诊断 | 每request两NIC各一半字节 |

native环境此前实际带宽理论值100/10Gbps，NUMA惩罚1/10。symmetric仅构造
**相同评分先验/边界**，不修改网卡，不声称两条真实物理路径性能完全相同。
EWMA仍接收真实完成反馈，因此对称组的运行中估计也可能分化。
均分组不固定计算出的权重；它仅覆盖整数Slice配额，保留inflight充放和EWMA更新。
固定分配必须每个1MiB请求都是8/8个64KiB Slice，观测到的实际分配字节逐次核验。
原算法每100次调用的probe仍按原规则运行；其均分结果保留并单独标记，probe权重
是诊断变换，不混入主权重序列的判定。

## 记录与阶段

- 新的独立影子库；只增加有界内存中的逐决策记录与测试控制，不改生产源码/安装包。
- 每决策记录：时间、线程槽/上下文/selector、probe标记、两NIC权重、评分、
  评分时的inflight/BW/NUMA惩罚、实际分配字节。使用捕获的局部变量，不重新读状态。
- 热路径不写文件、不分配堆内存；最多4个线程槽×200000条记录，溢出即拒绝该样本。
  单记录152字节，记录内存上限121.6MB；保留原50ms观测用于独立交叉核对。
- 测量结束后才导出。单caller的决策时间与提交时间顺序关联，核验一请求一条记录；
  测量边界跨越产生的至多一条缺失单列，内部缺失、重复或多上下文混接均拒绝。
- 先做结构测试与短功能检查，再做原V2和native-free的3组30秒观测控制。
  主矩阵4组×2负载×3重复=24次，每次60秒、预热5秒，块内固定种子随机顺序。
- 分析主区间固定为测量第10–60秒；前10秒单列启动过程，不用单调启动收敛冒充震荡。
- 同时核验计划输入恒定，报告实际提交间隔、提交前等待和每秒提交量波动。
  “计划输入匀速”与“实际注入完全均匀”分开；不删去注入不均的样本。

## 预设判据

1. 主指标是带5个百分点滞回的转折点：只有从运行极值反向移动至少5pp才确认反转，
   小变化不计。1pp和10pp只作预先声明的敏感性分析。
2. “持续大幅往返”需同时满足：稳态权重P95−P5≥10pp；50秒主区间至少10个
   完整往返；5个10秒子区间中至少4个各含3个完整往返。一个完整往返需要两个
   相反方向的已确认振幅，不把单个尖峰计成长期持续现象。
3. 一个条件3/3重复满足才称可重复复现；否则报告各次结果和范围，不能改变阈值追求阳性。
4. “持续往返/抖振”允许不规则周期。只有至少10个完整周期、周期时长CV≤0.25，
   且三个连续子区间各至少3周期、周期中位数相差不超过20%，才额外称“近周期”；
   周期仅是该时间分辨率下的描述，不证明自激机理或吞吐因果关系。
5. 权重、逐请求Slice份额、250ms聚合分配份额分别判定。权重层往返不能自动推导
   宏观流量也同等往返。probe剔除与保留的结果分别保存。
   超过1秒的逐决策记录空窗不连接计反转；250ms聚合份额不补空桶，也不跨空桶计反转。
   两条归一化权重互补是定义本身，不能把它们的负相关当作震荡证据。
6. 观测控制报告旧V2原生反转计数、份额波动和性能差异，不把新增trace产生的
   不确定性隐藏掉，也不凭3对运行宣称零观测开销。

输出固定重复2的全程及第10–12秒放大曲线，不挑选最极端的一次。所有重复的判定、
转折点、周期与原始数据均保存。最终报告分别回答：是否复现、幅度/频率/持续性、
固定均分后是否仍存在、对称先验下是否仍存在、能与不能推导什么。
