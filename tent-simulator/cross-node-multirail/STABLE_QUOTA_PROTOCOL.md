# SQ：稳定配额与有限修正，2026-09-29

## 范围与可证伪目标

本轮为真实跨机 TENT 双轨稳态对照，不是仿真。仅改变通过原批量门槛后的双轨、16×64KiB 等长 Slice 分配。单 caller、1MiB/request、Q128、NUMA0、两端原六 lanes；发送 A10 双 erdma，接收单 erdma。所有原始数据、构建、日志、报告放 Git 外。旧库和生产代码不改。

三个策略：原 O 观测库 reference；稳定容量配额 stable；稳定配额加有限队列修正 bounded。原 EWMA、候选健康/NUMA过滤、原每100次探测、重试保持。新策略的正常决策权重是实际消费的目标配额，原逆分数仅作诊断；探测权重不得混入正常权重统计。fallback 和单轨不宣称已验证故障恢复。

## 冻结规则

复用当日 RB 单轨标定 S0=738721792 B/s、S1=711808341.3333334 B/s 作为有效路径参考（包含当时 NUMA 成本，不宣称物理容量），参考指纹记录在计划中。原算法先验完全保留，不将改进全部归因于滤波。配额比 S0/(S0+S1)，将每256请求的总 Slice 数就近量化，预先生成均匀分散的整数配额表。普通请求查表并推进一次，不增加逐 Slice 债务循环、不增加等待。16片的表大部分8:8、少量9:7；这种确定性量化轮换须与目标控制震荡分开报告。

bounded 每次正常请求累计 d=Q0/C0-Q1/C1，100ms 以上形成一个非重叠窗口，使用请求样本平均（不是时间加权，也不是实际剩余线速工作）。阈值 H=1MiB/min(C0,C1)。均值>H建议偏移-1片，<-H建议+1片，其余建议0。连续三个相同建议窗口才修改偏移；偏移只能-1/0/+1，偏移本身直接翻转最多2片；叠加配额表的整数轮换，相邻请求的实际分配最多可变化3片。请求间空闲>200ms时清空窗口与确认状态、恢复基础配额。阶段1不重标定基础配额，不新建容量估计器；不能宣称适应任意持久容量变化。偏移表启动时预生成。原探测不推进表或控制器。

上述“最多3片”为测量后的文字澄清，算法和参数没有修改。冻结的原协议保存在输出目录source-snapshot中；原文的“最多2片”仅适用于控制器偏移，不能用于声称实际相邻分配变化上界。

## 验证路径

1. SSH内 C++ ASan/UBSan 检查守恒、完整256周期比例误差、空闲重置、连续确认和修正上界；Python独立逐请求重放检查状态与真实配额。执行前冻结源码/库指纹。
2. 三策略各一次8s+1s预热 pilot；任何失败原样保留并停止，不静默重跑。
3. 三策略×225/675 requests/s×3重复，每次60s+5s预热，固定随机顺序。输入为1.8874368/5.6623104Gbps，沿用RB整数到达，标签20/60%仅名义。
4. 三策略×3重复饱和对照，每次30s+5s预热；不能用固定输入替代峰值性能筛选。本轮9次饱和是初筛，不是生产非劣证明。
5. 停流后分析与画图。稳态失败先报告，不自动追加参数搜索；通过初筛后再设计动态负载与故障专项，后两项不在本轮完成声明内。

## 指标与判定

正常决策目标权重 P95-P5(pp)、1/5/10pp完整往返/s、数值更新率；实际逐请求配额切换率、250ms字节份额跨度/标准差/往返、整体字节比例；吞吐、250ms吞吐CV、端到端P99、1s P99窗口CV、分配调用平均耗时；失败/残留请求/数据校验/观测完整性。保留10–60s主窗口和0–60s全曲线，阴影为0.5s内min/max，不是置信区间。饱和采用自身完整测量窗口作性能比较，不套10–60s震荡判据。

稳态稳定性初筛：两个输入档权重与250ms实际分配跨度配对中位至少下降50%；吞吐CV、P99窗口CV不得恶化；正常配额切换另报（确定性8/9轮换不能冒充在途迁移）。性能初筛：饱和吞吐配对中位比>=0.98且任一重复>=0.95；固定输入P99配对中位<=1.05且任一重复<=1.10。分配开销独立报告，不能以均时推断P99。三个重复不提供充分统计功效，不把初筛当最终验收；不依据结果放宽门槛。

数据一致性沿用现有接收slot最终校验，报告其覆盖范围，不夸大为每次请求接收端逐字节独立校验。故障、负载阶跃、多caller、混合请求大小、批量门槛以下路径及长期运行仍待验证。
